Numerical methods

Experiments use analytical solutions where available. Examples include the exact exponential RC response, Fresnel power coefficients for a lossless interface, and a root solve for Kepler’s equation. Quadratic drag and driven oscillator modes use numerical integration. The circuit builder solves nodal equations with capacitor history and a finite time step. Inspect the Model tab and the experiment source for assumptions.

Development

The source archive includes installation and deployment instructions, a description of the application architecture, each experiment’s model and regression tests. Notebook entries and recorded measurements are stored on the device.
